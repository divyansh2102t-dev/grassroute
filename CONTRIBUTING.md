# Contributing to 🌿 GrassRoute

Thank you for helping make GrassRoute better for hikers, runners, gardeners, and outdoor explorers around the globe!

This repository is participating in **Hacktoberfest 2026**.

## 🎯 Good First Issues & Ways to Contribute

1. **Regional Tree & Foliage Data:**
   Open `fieldguide.js` and add native tree species with autumn color shifts, leaf outlines, and trail clues for your continent or bio-region.
2. **Bird Calls & Mnemonics:**
   Add songbirds or raptors common to your region with their phonetic songs ("Who cooks for you?", "fee-bee", "tea-kettle-tea-kettle").
3. **Garden & Frost Dates:**
   Expand the frost calendar in `fieldguide.js` with microclimate adjustments, Mediterranean / sub-tropical gardening calendars, or Southern Hemisphere autumn dates.
4. **Localization:**
   Translate field guide summaries or sensory trail prompts into Hindi, Spanish, French, German, or Japanese.

## 🛠️ Development Workflow

1. Fork the repo and clone your fork.
2. Run a local server:
   ```bash
   python -m http.server 8000
   ```
3. Test your changes in Chrome or Edge with WebGPU enabled.
4. Open a clean Pull Request with a clear description of the new species or features added.
